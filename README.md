# ars-nova-ops

**Ars Nova Singers - custom WordPress plugin.** Canonical source (private use; not distributed).

- Current version: 1.4.0. Installed on STAGING and LIVE.
- Admin-only REST endpoints to install/update/activate/deactivate/delete WordPress plugins by command (wraps core Plugin_Upgrader). Also: allow-listed core site options (1.2.0), read-only settings inspection (1.3.0), and raw content search + find-and-replace for pages/posts (1.4.0). Full route list in readme.txt.

Releases: each tag v<version> attaches the installable zip (top folder ars-nova-ops/). Install/update via the Ars Nova Ops installer or WP-admin upload.
